# CIA Triad Implementation in Python

This repository showcases a practical, code-first implementation of the **CIA Triad**:

- **Confidentiality**
- **Integrity**
- **Availability**

It’s designed as a portfolio-ready example for security engineering, data science, and backend roles.

---

## 1. Confidentiality

Implemented in `confidentiality.py`:

- AES-based encryption using **Fernet** (`cryptography`)
- Role-Based Access Control (RBAC)
- Hooks for Multi-Factor Authentication (MFA) using `pyotp`

Run:

```bash
python confidentiality.py
